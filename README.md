# RGB ELITE: Neon Core ⚡

Мини-игра для Telegram (Mini App) с ботом на Python.

Игрок тапает по неоновому ядру, которое меняет цвет (красный → зелёный → синий).
Если тапнуть, когда цвет ядра совпадает с **целью**, растёт комбо до **x3**.
Промах сбрасывает комбо, поэтому важна реакция, а не просто скорость тапов.

## Что есть в игре

| Функция | Зачем |
|---|---|
| Комбо по цвету | своя механика, отличает игру от обычных кликеров |
| Прокачка: сила тапа, батарея, авто-майнер | долгосрочная цель |
| Пассивный доход (до 3 ч офлайн) | повод вернуться |
| Лиги: Бронза → … → RGB Элита | статус и прогресс |
| Ежедневная награда с серией 7 дней | удержание игроков |
| Рефералы: +1000💎 другу, +500💎 новичку | бесплатный рост аудитории |
| Рейтинг (топ-50, `/top` в боте) | соревнование |
| Магазин за **Telegram Stars** ⭐ | **заработок** |

Сервер — источник истины: клиент присылает только количество тапов, а начисления
считаются на сервере с лимитами (энергия, максимум 20 тапов/сек, комбо ≤ x3).
Данные от Telegram проверяются по подписи, поэтому подделать чужой аккаунт нельзя.

## Файлы

- `index.html` — сама игра (Mini App). Без сервера работает в режиме «Офлайн-демо».
- `game.py` — игровая логика и баланс (цены, награды, лиги, товары магазина).
- `bot.py` — Telegram-бот + веб-сервер с API игры и базой SQLite.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN` и `WEBAPP_URL`.
4. Запусти:
   ```bash
   python bot.py
   ```
   Сервер слушает порт `8080` и отдаёт игру по адресу `/`.

Telegram открывает Mini App только по **HTTPS**, поэтому нужен хостинг или туннель:

- **Для теста:** `cloudflared tunnel --url http://localhost:8080` или `ngrok http 8080`.
  Полученный https-адрес впиши в `WEBAPP_URL`.
- **Для работы:** VPS, Railway, Render, Fly.io и т.п. (не забудь сохранять файл `game.db`).

Дополнительно в @BotFather: `/newapp` (Mini App с прямой ссылкой `t.me/бот/app`)
и `/setmenubutton` (кнопка «Играть» рядом с полем ввода).

## Как зарабатывать

- **Telegram Stars** — уже встроено: Турбо x2, полная энергия, мешок кристаллов.
  Цены и товары меняются в `SHOP` в `game.py`. Stars можно вывести через Fragment.
- **Реклама** — рекламные блоки (например, Adsgram) за награду в игре.
- **Продажа проекта** — готовая игра с аудиторией продаётся дороже, чем просто код.
  Покупателю важны цифры: сколько игроков, сколько возвращаются, сколько платят.

## Настройка баланса

Все числа в начале `game.py`: энергия, цены прокачки, награды, пороги лиг, бонусы за друзей.
Если меняешь их, поменяй и копию `CFG` в `index.html` (она нужна только для офлайн-демо;
в Telegram игра получает настройки с сервера).
