# GIFT LAB 🎁

Telegram Mini App + бот на Python: коллекционные подарки и **апгрейд** в стиле CS.

## Как играть

1. **Кейсы**: бесплатный каждые 4 часа, Базовый (150💎) и Премиум (1200💎).
   Открываются с рулеткой, у каждого кейса видны шансы редкостей.
2. **Подарки**: 18 штук и 5 редкостей, от 🧸 Мишки (10💎) до 🏆 Кубка чемпиона (25 000💎).
   Каждый экземпляр получает свой **номер #**, а фон (Неон, Золото, Радуга) увеличивает цену в 1.3–5 раз.
3. **Апгрейд**: выбираешь до 6 своих подарков и цель подороже (или кнопки x1.5 / x2 / x5 / x10 / x20).
   Шанс = твоя цена ÷ цена цели − 8%, максимум 75%. Крутится колесо: стрелка в зелёной зоне — забираешь цель,
   нет — ставка сгорает.
4. **Продажа**: любой подарок можно продать обратно за его цену.
5. **Лента**: крутые выпадения и апгрейды всех игроков в реальном времени.
6. **Топ коллекционеров**, **ежедневная награда** (серия 7 дней), **рефералы**, покупка кристаллов за **Telegram Stars**.

## Честность и защита

- Все случайные числа выпадают **на сервере** (`random.SystemRandom`). Телефон только показывает анимацию,
  подкрутить результат нельзя.
- Сервер проверяет подпись Telegram, владельца каждого подарка, цены и лимиты.
- Минимальный шанс 1%: огромный разрыв в цене запрещён, а не округлён вверх (иначе была бы бесплатная выгода).
- **Вывода денег нет.** Stars покупают только внутриигровые кристаллы. Если добавить вывод
  или продажу подарков за реальные деньги, игра станет азартной, и её могут заблокировать.

## Экономика

Кейсы в среднем возвращают 82–86% своей цены, апгрейд забирает 8%, поэтому кристаллы не размножаются
бесконечно и покупка за Stars имеет смысл. Все числа лежат в начале `game.py`. Если меняешь их,
поменяй копию `CFG` в `index.html` (она нужна только для офлайн-демо, в Telegram настройки приходят с сервера).

Проверить баланс кейсов:
```bash
python -c "import game; [print(k, game.case_expected_value(k)) for k in game.CASES]"
```

## Файлы

- `index.html` — игра (Mini App). Без сервера работает как «офлайн-демо» с сохранением в браузере.
- `game.py` — подарки, кейсы, шансы, награды, магазин.
- `bot.py` — Telegram-бот + веб-сервер (aiohttp) + база SQLite (`giftlab.db`).

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. `pip install -r requirements.txt`
3. Скопируй `.env.example` в `.env`, заполни `BOT_TOKEN` и `WEBAPP_URL`.
4. `python bot.py`: сервер слушает порт `8080` и отдаёт игру по адресу `/`.

Telegram открывает Mini App только по **HTTPS**:
- для теста: `cloudflared tunnel --url http://localhost:8080` или `ngrok http 8080`, полученный адрес впиши в `WEBAPP_URL`;
- для работы: VPS, Railway, Render, Fly.io (файл `giftlab.db` должен сохраняться между перезапусками).

В @BotFather также стоит сделать `/newapp` (ссылка вида `t.me/бот/app`) и `/setmenubutton` (кнопка рядом с полем ввода).

Команды бота: `/start` (с реферальной ссылкой), `/top`, `/paysupport` (Telegram требует её для оплаты Stars).
